# 美签 DS-160 审核与家庭面签模拟（Claude Code Skill）

一个基于 **Claude Code** 的美国 **B1/B2** 签证准备技能，以**家庭为单位**（主申请人 + 其他成年成员 + 未成年子女）提供两项核心能力：

1. **DS-160 完整表单审核** —— 从签证官视角审核多份 DS-160，定位前后矛盾、高风险因素、常见填写错误，并做跨成员一致性比对，输出**中文审核报告**（每条发现标注问题所在表单页码）。
2. **家庭一起面签模拟** —— 中文出题 + 英文模拟 + 中文逐答点评，基于真实 DS-160 资料个性化提问，结合持续更新的面签题库（含广州领区专项、2026 新政必答题、最新面签实录、敏感国家出境记录、拒签案例复盘）。

技能采用 **主 agent + 三子 agent 流水线**：`DS-160 处理 → 审核 → 面签模拟`，子 agent 之间经**中间文件**衔接（一次解析、多次复用）。

## ✨ 功能特性

| 模块 | 能力 |
|------|------|
| **DS-160 处理** | 解析多份 DS-160 完整表单 PDF（pypdf 文字提取，图片/扫描页可选腾讯云 OCR 兜底）；逐页记录字段页码；自动识别成员类型（成人/未成年） |
| **DS-160 审核** | 四维审核：① 前后矛盾 ② 高风险因素（214(b) 移民倾向 / 行政审查）③ 常见填写错误 ④ 与真实情况一致性（依赖用户补充真实情况，未补充标注"未执行"） |
| **跨成员比对** | ≥2 份表单时比对家庭住址、在美联系人、行程计划、直系亲属互填等应一致字段 |
| **审核报告** | 中文报告：总体结论 + 逐成员四维审核 + 跨成员一致性 + 面签提示/易被质疑点；每条发现含风险等级 + 字段页码 + 修改建议 |
| **面签模拟** | 家庭一起面签场景还原；主申请人主答、可切换成员；中文出题 / 英文模拟 / 中文逐答点评 |
| **个性化提问** | 基于 DS-160 真实资料出题（个性化为主，≥ 60%），结合成人/儿童分龄题库 |
| **题库持续更新** | 整合网络最新面签问题：2026 新政必答题（含非洲/庇护衍生题）、广州领区专项、最新面签实录（Agent 经小红书/Exa 主动检索）、敏感国家出境记录、探亲家庭专项、拒签案例复盘、二签注意事项，均标注来源与日期 |

## 🏗️ 架构

```
用户触发（/us-visa 或自然语言）
        │
        ▼
┌─ 主 agent（编排层）────────────────────────────┐
│  · 确认模式与输入位置 · 调度流水线 · 清理中间文件   │
└───────────────────────────────────────────────┘
        │
        ▼  一次解析、多次复用（中间文件衔接）
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ ds160-       │ ──► │ ds160-       │ ──► │ interview-   │
│ processor    │     │ auditor      │     │ simulator    │
│ 解析 PDF      │     │ 四维审核      │     │ 家庭面签模拟  │
│ 生成中间文件   │     │ 生成中文报告   │     │ 英文问答+点评 │
└──────────────┘     └──────────────┘     └──────────────┘
```

- 三个子 agent 定义于技能 `agents/` 目录，职责单一、可独立维护
- 子 agent 只读**中间文件**，不重复解析源 PDF
- 中间文件为**临时产物**：用户指定位置落盘，会话结束由主 agent 清理，不纳入版本库

## 🚀 快速开始

### 环境要求

- **Claude Code**（CLI）
- **Python 3 + pypdf**（PDF 文字层提取；未安装时文字版 PDF 无法提取，图片型 PDF 走 OCR）

### 安装

```bash
# 1. 克隆仓库
git clone <本仓库地址> us-visa-skill
cd us-visa-skill

# 2. 安装技能（软链接到 Claude Code 用户级 skills 目录）
ln -s "$(pwd)/skills/us-visa" ~/.claude/skills/us-visa

# 3.（可选）安装 OCR 兜底依赖技能，仅图片型/扫描型 PDF 需要
git clone https://github.com/TencentCloud/tencentcloud-ocr-skills ~/.claude/skills/tencentcloud-ocr
```

> **注意**：`skills/us-visa` 是一个完整技能目录，请保留其内部的 `SKILL.md`、`agents/`、`references/` 结构；不要只软链 `SKILL.md`。

### 使用

启动 Claude Code 后，通过 `/us-visa` 或自然语言（如"帮我审核 DS-160""面签模拟"）触发，然后：

1. 选择操作模式：**① DS-160 审核 ② 面签模拟 ③ 全流程**
2. 指定输入位置：含 DS-160 PDF 的文件或目录（技能只读取你指定的位置）
3. 技能自动识别家庭成员并请你确认**主申请人**
4. 按模式执行：审核 → 生成中文报告；模拟 → 逐答点评 + 收尾总结

示例：

```text
/ us-visa
> 全流程
> 输入位置：/Users/me/visa/DS-160/
确认：发现 2 份表单（张冰·成人 / 冯奕安·未成年），主申请人为张冰？
> 是
```

## 🔍 审核功能详解

- **四维审核**：前后矛盾、高风险因素、常见填写错误、与真实情况一致性（维度④依赖用户补充真实情况；未补充时标注"未执行"，**不默认通过**）
- **跨成员一致性比对**：≥2 份表单时，以成员维度展示住址 / 在美联系人 / 行程 / 直系亲属互填等差异
- **防误报**：内置"表单设计常识"清单——未成年随行子女不填行程、同行人字段无出生日期等属表单设计使然，不会误报为错误
- **字段页码定位**：每条发现标注问题所在表单页码（如"第 3 页 · Occupation"）
- **照片类问题不在审核范围**：仅审核文字字段

## 🎙️ 面签模拟功能详解

- **家庭场景**：还原"问候 → 提问 → 追问 → 收尾"真实流程，主申请人主答、可随时切换其他成员（未成年用简化题库）
- **语言阶段规则**：中文开场热身 → 遇需警惕/小心处（高风险、易被追问点）切换英文提问（警示信号）→ 切换后全英文问答 → 中文逐答点评
- **逐答点评**：回答质量评估 + 风险提示 + 优化建议（附可复用的英文表述示例）
- **题库**：成人标准 + 儿童简化；含 2026 新政必答题（伤害/迫害、庇护/滞留、非洲行程等 9 题）、广州领区专项、最新面签实录（9 篇真实问答，2025-12~2026-08）、敏感国家出境记录、探亲家庭专项、拒签案例复盘（压力测试素材）

## 🔒 隐私与数据安全

- **数据本地流转**：敏感信息（DS-160 内容、审核报告、中间文件）**不脱敏**，仅在本仓库内流转，不离开本地
- **唯一外部流转**：用户**主动选择**的腾讯云 OCR（仅图片型/扫描型 PDF），凭据由用户每次手动输入、不存储
- **临时产物**：中间文件、审核报告为临时产物，会话结束清理；均已在 `.gitignore` 中忽略（`*.pdf`、`ds160-intermediate.json`、`*DS160审核报告.md`），**不会发布到 GitHub**
- **不采集遥测**：技能无任何网络上报

## 🚫 明确不做

- 签证缴费、面签预约、签证状态查询
- 材料清单辅助（仅审核表单本身）
- 其他国家签证相关功能
