## 需求概述

本技能为家庭（主申请人+其他成年成员+未成年子女）申请美国 B1/B2 签证提供两项能力：**① 读取审核多份 DS-160 完整表单 PDF**，从签证官视角进行前后矛盾、高风险因素、常见错误、真实情况一致性及跨成员一致性审核，输出中文审核报告到用户指定位置；**② 模拟家庭一起面签场景**，中文出题+英文模拟+中文点评，基于真实资料个性化提问并结合通用题库，对每个回答给出点评与优化建议。技能采用**主 agent + 三子 agent 架构**（DS-160 处理 / 审核 / 面签模拟），由主 agent 按流水线编排，DS-160 处理 agent 生成结构化中间文件衔接后续环节。敏感个人信息**不脱敏**，数据仅在本仓库内流转处理，唯一外部流转为用户主动选择的腾讯云 OCR（见 NFR-SEC-001）。

## 需求分类清单

### 模块一：DS-160 读取与审核

| 需求编号 | 需求名称 | 需求描述 | 优先级 | 需求类型 | 来源轮次 |
|---------|---------|---------|--------|---------|---------|
| REQ-001 | 输入位置指定 | 用户在调用时指定输入文件或目录（可含多份 DS-160 PDF），技能从指定位置读取，不擅自扫描其他位置 | P0-必须 | 功能需求 | 轮次2-答4（位置指定）；轮次1-答4（输入为多份 PDF） |
| REQ-002 | PDF 解析与字段提取 | 解析含完整表单内容的 DS-160 PDF，提取结构化字段（个人信息、护照、行程、工作、家庭、安全类问题等），支持多份 | P0-必须 | 功能需求 | 轮次2-答1 |
| REQ-003 | 家庭成员识别 | 从各 PDF 提取出生日期等字段，自动识别成员类型（主申请人/其他成年成员/未成年子女），支撑跨成员审核与分龄面签题库 | P0-必须 | 功能需求 | 轮次1-答4、轮次2-答3 |
| REQ-004 | 前后矛盾审核 | 检测单份表单内部的前后矛盾（如行程与住址、工作与时间线等），定位矛盾字段并说明 | P0-必须 | 功能需求 | 轮次1-答5 |
| REQ-005 | 高风险因素审核 | 识别易触发拒签（如 214(b) 移民倾向）或行政审查的高风险回答与组合，给出风险等级与说明 | P0-必须 | 功能需求 | 轮次1-答5 |
| REQ-006 | 常见填写错误提醒 | 对照 DS-160 官方字段规范，提醒常见填写错误（如格式、必填遗漏、逻辑不合理项） | P0-必须 | 功能需求 | 轮次1-答5 |
| REQ-007 | 与真实情况一致性审核 | 结合用户在会话中补充的真实情况说明，审核表单与实际的一致性，提示面签时易被质疑的点 | P0-必须 | 功能需求 | 轮次1-答5 |
| REQ-008 | 跨家庭成员一致性审核 | 比对多份 PDF 中应一致的信息（家庭住址、在美联系人、行程计划、直系亲属信息等），提示成员间矛盾（依赖 REQ-003 家庭成员识别） | P0-必须 | 功能需求 | 轮次2-答2 |
| REQ-009 | 审核报告输出 | 生成中文审核报告：逐字段检查（每条发现标注问题所在表单页码）+风险等级+修改建议，输出到用户指定位置 | P0-必须 | 功能需求 | 轮次2-答4 |

### 模块二：面签模拟

| 需求编号 | 需求名称 | 需求描述 | 优先级 | 需求类型 | 来源轮次 |
|---------|---------|---------|--------|---------|---------|
| REQ-010 | 家庭一起面签场景模拟 | 模拟家庭多成员一同面签的场景，区分主应答者（主申请人）与次要应答者（其他成员），还原真实面签流程 | P0-必须 | 功能需求 | 轮次2-答3 |
| REQ-011 | 中文出题+英文模拟+中文点评 | 出题与点评使用中文，模拟对话使用英文（贴近真实面签语言环境） | P0-必须 | 功能需求 | 轮次1-答6 |
| REQ-012 | 个性化提问 | 基于已解析的 DS-160 真实资料（个人背景、工作、行程、家庭）生成针对性问题 | P0-必须 | 功能需求 | 轮次1-答6 |
| REQ-013 | 通用题库 | 内置贴近真实 B1/B2 面签场景的通用问题库，覆盖常见主题（访美目的、行程、工作、资金、国内约束力等） | P1-重要 | 功能需求 | 轮次1-答6 |
| REQ-014 | 逐答点评与优化建议 | 对用户的每个回答给出点评：回答质量评估、风险提示、优化建议（更稳妥的表述方式） | P0-必须 | 功能需求 | 轮次1-答6 |
| REQ-015 | 儿童成员简化问题 | 对未成年子女成员套用简化版问题（如姓名、年龄、学校、随行人员），符合实际面签中儿童被问问题的深度 | P1-重要 | 功能需求 | 轮次1-答4、轮次2-答3 |
| REQ-021 | 面签题库扩充（广州领区与最新问题） | 扩充面签题库：补充通用主题追问（行程/工作/资金/约束力等细节）、广州领区专项、最新面签实录、敏感国家出境记录、2026 新政必答（含非洲/庇护衍生题）、二签注意事项；最新面签问题由 Agent 经小红书搜索/Exa 检索主动获取（或用户提供）后整合进题库并标注来源与日期，持续更新（依赖 REQ-013 通用题库） | P1-重要 | 功能需求 | 轮次4-答1/2 |

### 模块四：子 Agent 架构与编排

| 需求编号 | 需求名称 | 需求描述 | 优先级 | 需求类型 | 来源轮次 |
|---------|---------|---------|--------|---------|---------|
| REQ-017 | 子 Agent 职责划分 | 技能由主 agent 与三个独立 subagent 组成：① DS-160 处理 agent（解析 PDF、生成中间文件）② 审核 agent（四维审核+跨成员比对）③ 面签模拟 agent（家庭面签模拟）；各 agent 职责边界清晰、可独立维护 | P0-必须 | 功能需求 | 轮次3-答1/5 |
| REQ-018 | 主 Agent 流水线编排 | 主 agent 按"处理 → 审核 → 模拟"顺序调度三个子 agent，通过中间文件衔接，用户可中途切入某一环节 | P0-必须 | 功能需求 | 轮次3-答1 |
| REQ-019 | 中间文件生成与衔接 | DS-160 处理 agent 将解析结果写为结构化中间文件（JSON），供审核/模拟 agent 读取，避免重复解析 | P0-必须 | 功能需求 | 轮次3-答2/3 |
| REQ-020 | 中间文件临时性与清理 | 中间文件存放于用户指定位置，属临时产物；会话结束由主 agent 清理，不纳入版本库 | P0-必须 | 功能需求 | 轮次3-答2/7 |

## 子 Agent 职责归属映射

现有需求由主 agent 与三个子 agent 分工承担：

| 承担者 | 承担需求 |
|--------|---------|
| 主 agent（编排层） | REQ-001 输入位置指定、REQ-016 技能触发方式、REQ-018 流水线编排、REQ-020 中间文件清理 |
| DS-160 处理 agent | REQ-002 PDF 解析与字段提取、REQ-003 家庭成员识别、REQ-019 中间文件生成 |
| 审核 agent | REQ-004 前后矛盾、REQ-005 高风险因素、REQ-006 常见错误、REQ-007 真实情况一致性、REQ-008 跨成员一致性、REQ-009 审核报告输出 |
| 面签模拟 agent | REQ-010 家庭面签场景、REQ-011 中英中交互、REQ-012 个性化提问、REQ-013 通用题库、REQ-014 逐答点评、REQ-015 儿童简化问题、REQ-021 面签题库扩充 |

> REQ-017（子 Agent 职责划分）为架构级需求，由"主 agent + 三子 agent"整体承载，不单独归属某一 agent。
