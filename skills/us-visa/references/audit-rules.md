# DS-160 四维审核规则

> 用途：DS-160 审核时执行四类审核维度的具体规则与高风险模式库。
> 每条发现的输出格式：**风险等级（高/中/低）+ 字段定位 + 说明 + 修改建议**。

---

## 维度一：前后矛盾（表单内部一致性）

检测单份表单内部自相矛盾。

| 规则 | 检查逻辑 | 典型示例 |
|------|---------|---------|
| 行程日期 vs 停留天数 | 起止日期推算天数与"拟停留天数"字段比对 | 填 7 天行程但停留天数写 14 天 |
| 行程 vs 在美地址 | 到访城市与在美地址所在城市是否匹配 | 行程写纽约但在美地址写洛杉矶 |
| 工作 vs 时间线 | 当前工作起始日与教育/上一份工作是否重叠或断裂 | 教育与工作同期；上一份工作空窗未解释 |
| 教育经历 | 各段起止时间无重叠、无断档 | 大学与高中时间重叠 |
| 婚姻状态 vs 家庭信息 | 婚姻状况与配偶字段是否自洽 | 填"已婚"但配偶信息为空/矛盾 |
| 姓名/护照 | 各字段姓名拼写、护照号完全一致 | 曾用名字段与主姓名字段冲突 |
| 联系方式 | 电话/邮箱格式与真实性 | 格式错误或位数不对 |

## 维度二：高风险因素（拒签/行政审查风险）

识别可能触发 **214(b) 移民倾向拒签** 或 **行政审查（AP）** 的回答组合。

### 214(b) 移民倾向风险（国内约束力弱）

| 风险模式 | 风险点 | 规避/解释建议 |
|---------|--------|--------------|
| 单身 + 无房产 + 无稳定工作 + 短行程 | 约束力弱，移民倾向疑点 | 强调工作稳定性、家庭联系、资金证明、明确返程安排 |
| 收入明显不足支撑行程 | 资金不匹配 | 补充资金证明、费用支付人说明、行程合理性 |
| 年轻 + 首次出国 + 直接赴美 | 疑点较大 | 准备清晰的访美目的与返程约束力证据 |
| 频繁短期访美 | 疑似非旅游目的 | 解释每次到访的真实目的与间隔合理性 |

### 行政审查风险

| 风险模式 | 说明 |
|---------|------|
| 敏感职业/背景 | 军事、航天、核能、网络安全、高精尖科技等，可能触发 AP；如实填写即可，提示可能延迟 |
| 敏感目的地/行程 | 涉及受限地区行程，提示风险 |
| 曾涉安全类问题 | 安全背景部分任何"是"的回答均为高风险，需谨慎核对 |

### 其他高风险

| 风险模式 | 说明 |
|---------|------|
| 在美有直系亲属（尤其已获绿卡/国籍） | 移民倾向强关联，提示准备解释 |
| 有拒签史 / 被拒绝入境史 | 必须如实；提示准备解释上次拒签原因与情况变化 |
| 曾逾期停留 / 签证违规 | 极高风险，如实申报 + 准备充分解释 |
| 回答与实际不符的迹象 | 一旦被认定材料造假，后果严重（禁止入境） |

## 维度三：常见填写错误

对照官方字段规范提醒。

| 错误类型 | 示例 |
|---------|------|
| 日期格式错误 | 混淆 MM/DD/YYYY 与 DD/MM/YYYY |
| 姓名拼写错误 | 与护照不一致、字母大小写错误 |
| 必填遗漏 | 住址、联系方式、雇主信息为空 |
| 地址不完整 | 未填到门牌号/城市层级 |
| 电话/邮箱格式错误 | 位数不足、格式非法 |
| 逻辑不合理 | 出生日期晚于学历起始日等 |
| 信息与证件不符 | 与护照、出生证明、在职证明不一致 |

## 维度四：与真实情况一致性

依赖用户补充的真实情况，比对表单与实际。

| 规则 | 说明 |
|------|------|
| 触发方式 | 用户在会话中补充实际信息（如"实际工作已变更""实际收入不同"） |
| 比对输出 | 差异点 + 面签时易被质疑的点 + 应对话术 |
| 未补充时 | 在报告中明确标注"一致性审核未执行"，**不得默认通过** |
| 面签提示 | 对每个差异点给出"若面签官追问如何解释"的建议 |

## 审核输出模板

对每个成员：

```
### 成员：<姓名>（<成人/未成年>，<主申请人/其他>）

**① 前后矛盾：**
- [高/中/低] <字段>：<说明> → 建议：<修改建议>

**② 高风险因素：**
- [高/中/低] <风险模式>：<理由> → 建议：<规避/解释建议>

**③ 常见填写错误：**
- [低] <字段>：<错误> → 建议：<正确写法>

**④ 真实情况一致性：** <已执行 / 未执行（未补充真实情况）>
- [差异点] ...

**面签提示/易被质疑点：**
- ...
```

> 附：真实面签中 90% 的拒签源于"约束力不足"与"材料/回答不一致"两类，审核时对这两类问题优先级最高。
