# DS-160 字段核对清单

> 用途：DS-160 审核时按本清单核对字段提取完整度，并作为"常见填写错误"与"前后矛盾"审核的字段基线。
> 依据：美国 DS-160 官方表单结构（Section 顺序）。字段以完整表单 PDF 呈现的实际内容为准。

---

## 一、个人信息（Personal Information）

| 字段 | 审核关注点 |
|------|-----------|
| 姓 / 名（拼音） | 与护照拼写**完全一致**（含大小写、连字符）；曾用名是否如实填写 |
| 出生日期 | 与护照/出生证明一致；格式正确 |
| 出生国家 / 出生城市 | 与护照签发页一致 |
| 国籍 | 是否如实；多重国籍需申报 |
| 性别 | 与护照一致 |
| 婚姻状况 | 与家庭信息部分相互印证 |
| 身份证号 | 格式正确、真实 |
| 联系电话 / 邮箱 | 格式正确、可联系 |
| 当前住址 | 与家庭成员表单**一致**；是否填到门牌号级 |

## 二、护照信息（Passport Information）

| 字段 | 审核关注点 |
|------|-----------|
| 护照号码 | 与护照一致；与家庭成员表单互填信息一致 |
| 护照签发国家 / 签发地 | 与护照一致 |
| 签发日期 / 到期日期 | 真实；**到期日是否在行程结束日之后**（美签要求） |
| 是否有旧护照 | 如实申报，尤其旧护照含签证/出入境记录 |

## 三、旅行信息（Travel Information）

| 字段 | 审核关注点 |
|------|-----------|
| 拟到访美国日期 | 是否在可接受窗口内；与行程计划一致 |
| 拟在美停留时长（天数） | **与起止日期计算一致**（常见矛盾点） |
| 计划在美地址 | 与在美联系人/酒店信息一致；具体到城市 |
| 费用支付人 | 是否合理（自付/他人代付需自洽）；与资金证明一致 |

## 四、在美联系人（U.S. Contact）

| 字段 | 审核关注点 |
|------|-----------|
| 在美联系人或组织 | 与行程/在美地址一致；家庭成员间**必须一致** |
| 联系人关系 | 如实；与家庭信息中在美亲属交叉核对 |

## 五、家庭信息（Family Information）

| 字段 | 审核关注点 |
|------|-----------|
| 配偶信息 | 与家庭成员表单**互填一致**（婚姻状态、姓名、出生日期） |
| 子女信息 | 与各子女 PDF 核对；数量与构成一致 |
| 父母信息 | 出生国家等基本信息真实 |
| 在美直系亲属 | **高风险点**：是否有已移民/在美长期居留的直系亲属，需提示规避解释建议 |
| 兄弟姐妹 | 如填在美，提示解释 |

## 六、教育与工作经历（Education & Employment）

| 字段 | 审核关注点 |
|------|-----------|
| 教育经历 | 起止时间**无重叠、无断裂**；学校名称完整 |
| 当前工作单位 | 与"是否在职"自洽；单位名称与职位真实 |
| 当前工作地址 / 电话 | 格式完整、真实 |
| 过去 5 年工作经历 | **时间线连续**（常见矛盾点：空窗/重叠）；换工作逻辑自洽 |
| 工作描述 | 与职位匹配；与面签回答一致 |

## 七、安全和背景部分（Security and Background）

| 字段 | 审核关注点 |
|------|-----------|
| 一系列"是否"问题 | 逐项核对：健康、犯罪记录、涉毒、安全威胁、移民违规、逾期停留、拒签/拒绝入境史等 |
| 拒签史 / 被拒绝入境史 | **高风险点**：如有，提示准备解释口径 |
| 曾逾期停留 / 签证违规 | 高风险点，必须如实；提示面签话术 |
| 是否曾申请过美签 | 与签证历史交叉核对 |

## 八、其他

| 字段 | 审核关注点 |
|------|-----------|
| 是否由第三方协助填写 | 如实（机构代办需注明） |
| 确认页条码 / 申请号 | 一致性核对（若可见） |

---

## 跨成员一致性必比字段（≥2 份时）

| 字段 | 说明 |
|------|------|
| 家庭住址 | 全体成员一致 |
| 在美联系人 | 全体成员一致 |
| 行程计划（到访日期/城市/时长） | 全体成员一致 |
| 直系亲属互填 | A 填的配偶信息 = B 表单的实际信息 |
| 紧急联系人 / 费用支付人 | 逻辑自洽 |

---

## 审核优先级提示

- **P0 级字段**（矛盾/错误后果严重）：护照拼写、出生日期、行程日期与天数、在美联系人、家庭成员互填、安全类问题。
- **P1 级字段**：工作经历时间线、教育经历、地址完整性、联系方式格式。
- **P2 级字段**：其他辅助信息。
