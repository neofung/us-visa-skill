## 性能需求

| 编号 | 需求描述 | 指标 | 目标值 | 测量方法 | 优先级 |
|------|---------|------|--------|---------|--------|
| NFR-PERF-001 | 解析多份 PDF 并生成审核报告在单次会话内完成 | 用户可感知等待 | ≤ 2 分钟（3 份 PDF 基准） | 实测 | P0 |
| NFR-PERF-002 | 面签模拟单轮问答（提问+点评）响应及时 | 单轮响应时间 | ≤ 30 秒（设计假定：对话式实时反馈的合理响应预期） | 实测 | P1 |

## 安全需求

| 编号 | 需求描述 | 安全类别 | 具体要求 | 优先级 |
|------|---------|---------|---------|--------|
| NFR-SEC-001 | 敏感数据流转边界 | 数据安全 | 除 Claude Code 运行时本身（Anthropic 会话处理）外，仅调用腾讯云 OCR API（依赖技能 tencentcloud-ocr）这一第三方云服务，且为**用户主动选择**、每次手动提供 SecretId/SecretKey；其余第三方云服务（其他 OCR、外部 LLM API 等）一律不调用。OCR 内容将上传至腾讯云服务器，用户已知悉 | P0 |
| NFR-SEC-002 | 不越权读取指定位置以外文件 | 数据安全 | 仅访问用户指定的文件/目录 | P0 |
| NFR-SEC-003 | 不进行脱敏处理（仓库私有） | 数据安全 | 保持原始数据完整，便于用户核对 | P0 |
| NFR-SEC-004 | OCR 凭据不落盘 | 数据安全 | SecretId/SecretKey 仅在会话内使用，不写入技能源码/文档/仓库、不缓存（见 TC-OTH-003） | P0 |
